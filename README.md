# ObraPro Suite 🏗️

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fmitorrgo-del%2Fobrapro-suite)

Software de presupuestos y control de márgenes para profesionales de reformas y construcción.

- **Herramienta Online Gratuita:** Calculador rápido integrado para posicionamiento orgánico en Google (SEO).
- **Sistema de Descarga Inmediata:** Plantilla inteligente `.xlsx` para Excel y Google Sheets con cálculo automático de margen neto, imprevistos y catálogo de partidas.
- **Pasarela de Cobro:** Integrada con PayPal.

## Despliegue en 1 Clic con Vercel
